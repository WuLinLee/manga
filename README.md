# 漫画沉浸式阅读增强脚本

一个面向多个在线漫画阅读网站的用户脚本，旨在减少阅读时的导航栏、工具栏和滚动条干扰，并为部分站点提供页码提示、全屏切换和快速翻页辅助。

## 功能一览

| 网站 | 主要功能 |
| --- | --- |
| MyComic | 顶部栏和底部栏默认收起，鼠标悬停时显示；隐藏滚动条；显示页码提示；点击图片上半部/下半部可尝试翻到上一页/下一页；点击页码提示切换全屏 |
| 拷贝漫画（Copy4000 / MangaCopy） | 漫画图片居中显示并限制在视口范围内；顶部栏和底部栏默认收起、悬停时显示；隐藏滚动条；点击漫画阅读区域可切换全屏 |
| Komiic | 阅读页的导航区域默认收起、悬停时显示；显示当前页码，并在识别到章节末页时记录总页数；提供快速向前翻页和快速向后翻页的控制区域；点击页码提示切换全屏 |
| MangaDex | 隐藏页面滚动条；固定页码信息的位置，并允许点击页码信息切换全屏 |

不同网站的页面结构和交互方式不同，因此功能并不完全相同。

## 支持网站

脚本的匹配规则覆盖以下域名及相应路径：

- [MyComic](https://mycomic.com/)：章节阅读页面
- [Copy4000](https://copy4000.com/)：章节页面
- [MangaCopy](https://mangacopy.com/)：章节页面
- [Komiic](https://komiic.cc/) / [Komiic](https://komiic.com/)
- [MangaDex](https://mangadex.org/)

脚本会根据当前访问的域名运行对应的功能。网站改版、浏览器全屏权限或站点自身的交互变化，都可能影响实际效果。

## 安装

### 一键安装

1. 在浏览器中安装用户脚本管理器，例如 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)。
2. 打开脚本的原始文件地址。
3. 在用户脚本管理器显示的安装页面中确认安装。

**脚本安装地址：**  
[点击安装漫画沉浸式阅读增强脚本](https://raw.githubusercontent.com/WuLinLee/manga/main/manga.user.js)

### 手动安装

也可以在用户脚本管理器中新建脚本，将仓库中的 [manga.user.js](https://github.com/WuLinLee/manga/blob/main/manga.user.js) 全部内容复制进去并保存。

## 使用方法

- **显示/隐藏导航栏：** 在 MyComic、Copy4000 / MangaCopy 和 Komiic 上，将鼠标移到页面顶部或底部的栏位附近，可显示被收起的工具栏。
- **全屏切换：** 根据网站不同，点击页码提示或漫画阅读区域切换全屏。浏览器可能会要求页面具备全屏权限。
- **MyComic 翻页：** 在漫画图片上半部点击可尝试上一页，在下半部点击可尝试下一页；具体行为取决于该页面的图片和分页结构。
- **Komiic 快速翻页：** 使用阅读区域左右侧的细条控制区域，可连续触发上一页或下一页操作。每次连续操作最多尝试 50 次；到达边界、找不到相应按钮或识别到下一话按钮时会停止。

这些操作基于网站当前的页面元素实现。如果站点更新了按钮文字或页面结构，对应功能可能暂时失效。

## 常见问题

**安装后没有效果？**  
确认用户脚本管理器已启用，并且当前网址属于上方列出的支持范围。安装或更新脚本后，刷新漫画阅读页面再试。

**工具栏找不到了？**  
在支持隐藏工具栏的站点，将鼠标移动到页面顶部或底部附近，工具栏应在悬停时显示。

**全屏无法开启？**  
请直接在页面上点击脚本提供的页码提示或对应阅读区域，并确认浏览器没有阻止全屏操作。

**快速翻页没有运行到章节末尾？**  
Komiic 的快速翻页依赖页面上的「上页 / 下页」等按钮，且单次连续操作有次数上限；网络延迟或站点改版也可能影响结果。

## 隐私与权限

脚本头部使用 @grant none，没有声明需要用户脚本管理器额外授予的 GM API 权限。脚本通过页面 DOM、样式和事件实现阅读辅助功能。
